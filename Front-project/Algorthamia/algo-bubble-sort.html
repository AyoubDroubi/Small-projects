Bubble Sort

information

  • Worst Case :  O(n^2) - When the array is in reverse order, every element needs to be compared and potentially swapped.
  • Average Case :  O(n^2) - It takes quadratic time even for partially sorted arrays.
  • Best Case : O(n) - When the array is already sorted, it only needs one pass to verify.
  • Design Technique :  Incremental Technique
  • Space Complexity :  O(1)     -     (in place)

Overview

Bubble Sort : is the simplest sorting algorithm that works by repeatedly swapping the adjacent elements if they are in the wrong order. This algorithm is not suitable for large data sets as its average and worst-case time complexity is quite high.

Definition : A simple sorting algorithm that repeatedly iterates through the array, compares adjacent elements, and swaps them if they're in the wrong order. This process continues until no more swaps are needed, indicating the array is sorted.

Steps

  1. Start at the beginning of the list
    • Compare each pair of adjacent elements.
    • If the elements are in the wrong order, swap them.
  2. Repeat step 1 until no more swaps occur:
    • This indicates the array is sorted.

Advantages

  1. Bubble sort is easy to understand and implement.
  2. It does not require any additional memory space.
  3. It is a stable sorting algorithm, meaning that elements with the same key value maintain their relative order in the sorted output.

Disadvantages

  1. Bubble sort has a time complexity of O(N2) which makes it very slow for large data sets.
  2. Bubble sort is a comparison-based sorting algorithm, which means that it requires a comparison operator to determine the relative order of elements in the input data set. It can limit the efficiency of the algorithm in certain cases.

Pseudo Code

begin BubbleSort(list) for all elements of list if list[i] > list[i+1] swap(list[i], list[i+1]) end if end for return list end BubbleSort

Code in Java

public class BubbleSort { public static void bubbleSort(int[] arr) { int n = arr.length; for (int i = 0; i < n - 1; i++) { for (int j = 0; j < n - i - 1; j++) { if (arr[j] > arr[j + 1]) { // Swap elements int temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp; } } } } }

Code in Python

def bubble_sort(arr): n = len(arr) for i in range(n-1): for j in range(0, n-i-1): if arr[j] > arr[j+1]: arr[j], arr[j+1] = arr[j+1], arr[j]

Example

1. Array Setup:



Start with an unsorted array. Let's use [6, 2, 3, 1, 5] as our example.
2. Iterations:

Bubble sort works by repeatedly iterating through the array to compare and swap elements.
For an array with n elements, you'll need n-1 iterations to ensure all elements are sorted.
3. First Iteration:

Compare the first two elements (6 and 2).
Since 6 is greater than 2, swap them: [2, 6, 3, 1, 5]
Continue comparing and swapping adjacent elements:
[2, 6, 3, 1, 5] -> [2, 3, 6, 1, 5] -> [2, 3, 1, 6, 5] -> [2, 3, 1, 5, 6]
Now the largest element (6) has "bubbled" to its correct position at the end.
4. Second Iteration:

Repeat the process, but this time you can stop before reaching the last element (which is already in its correct place):
[2, 3, 1, 5, 6] -> [2, 1, 3, 5, 6] -> [1, 2, 3, 5, 6]
Now the second largest element (5) is also in its correct position.
5. Subsequent Iterations:

Continue iterations until no more swaps are needed:
Third iteration: [1, 2, 3, 5, 6] (no swaps)
The array is now sorted: [1, 2, 3, 5, 6]
