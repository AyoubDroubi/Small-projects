Counting Sort

information

  • Worst Case :  O(n + k) - where n is the number of elements and k is the range of input values.
  • Average Case :  O(n + k)
  • Best Case : O(n + k)
  • Design Technique :  Incremental Technique - (Non-comparison)
  • Space Complexity :  O(k) - (out place) - Needs extra space to store the count array, where k is the range of input values.

Overview

Counting Sort : is a non-comparison-based sorting algorithm that works well when there is limited range of input values. It is particularly efficient when the range of input values is small compared to the number of elements to be sorted. The basic idea behind Counting Sort is to count the frequency of each distinct element in the input array and use that information to place the elements in their correct sorted positions.

Definition : A sorting algorithm that works by counting the occurrences of each distinct value in the input array, then using those counts to determine the positions of each value in the sorted array.

Steps

  1. Find the maximum value (k) in the input array.
  2. Create a count array of size k+1, initializing all counts to 0.
  3. Iterate through the input array and count the occurrences of each value in the count array.
  4. Modify the count array to store the cumulative sum of counts.
  5. Create an empty output array of the same size as the input array.
  6. Iterate through the input array again and place each element in its correct position in the output array based on the cumulative counts.
  7. Copy the output array back to the original array.

Advantages

  1. Linear time complexity for a limited range of input values.
  2. Efficient for large datasets with a small range of values.
  3. Stable sorting algorithm.

Disadvantages

  1. Space complexity can be high if the range of input values is large.
  2. Not suitable for general-purpose sorting when the range of values is unknown or unbounded.

Pseudo Code

procedure countingSort(A, k)
array C[0..k]
for i = 0 to k
C[i] = 0
for j = 1 to length(A)
C[A[j]] = C[A[j]] + 1
for i = 1 to k
C[i] = C[i] + C[i - 1]
for j = length(A) downto 1
B[C[A[j]]] = A[j]
C[A[j]] = C[A[j]] - 1
return B

Code in Java

public class CountingSort {
public static void countingSort(int[] arr, int k) {
int[] count = new int[k + 1];
int[] output = new
int[arr.length];

for (int i = 0; i < arr.length; i++) {
count[arr[i]]++;
}

for (int i = 1; i <= k; i++) {
count[i] += count[i - 1];
}

for (int i = arr.length - 1; i >= 0; i--) {
output[count[arr[i]] - 1] = arr[i];
count[arr[i]]--;
}

System.arraycopy(output, 0, arr, 0, arr.length);
}
}

Code in Python

def counting_sort(arr, k):
count = [0] * (k + 1)
output = [0] * len(arr)

for i in arr:
count[i] += 1

for i in range(1, k + 1):
count[i] += count[i - 1]

for i in arr[::-1]:
output[count[i] - 1] = i
count[i] -= 1

return output

Example



Here's a full example of Counting Sort step by step, using the array [3, 2, 1, 4, 3, 2]:



1. Find the maximum value (k):



k = 4 (the largest element in the array)

2. Create the count array:



count = [0, 0, 0, 0, 0] (size k+1)

3. Count occurrences in the input array:



count becomes [2, 2, 1, 1, 1] (counting 3s, 2s, 1s, 4s, and 0s)

4. Modify count array for cumulative sums:



count becomes [2, 4, 5, 6, 7] (each index now stores the sum of counts up to that point)

5. Create an empty output array:



output = [0, 0, 0, 0, 0, 0] (same size as the input array)

6. Place elements in output array:



Iterate through the input array in reverse order:

3 at index count[3]-1 (which is 5), so output becomes [0, 0, 0, 3, 0, 0]

2 at index count[2]-1 (which is 3), so output becomes [0, 0, 2, 3, 0, 0]

1 at index count[1]-1 (which is 1), so output becomes [1, 0, 2, 3, 0, 0]

And so on...

7. Copy output array back:



The final sorted array becomes [1, 2, 2, 3, 3, 4]
