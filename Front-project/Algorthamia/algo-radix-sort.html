Bubble Sort

information

  • Worst Case :  O(d*(n+k)) - where d is the number of digits, n is the number of elements, and k is the radix (base, typically 10 or 2).
  • Average Case :  O(d*(n+k))
  • Best Case : O(d*(n+k))
  • Design Technique :  Incremental Technique - (Non-comparison)
  • Space Complexity :  O(n+k)     -     (out place)

Overview

Radix Sort : is a linear sorting algorithm that sorts elements by processing them digit by digit. It is an efficient sorting algorithm for integers or strings with fixed-size keys.

Definition : A sorting algorithm that works by repeatedly distributing elements into buckets based on their individual digits, starting from the least significant digit and working towards the most significant digit.

Steps

  1. Determine the maximum number of digits (d) in the largest element.
  2. For each digit position (d-1 to 0):
    • Create 10 buckets (for base 10) or 2 buckets (for base 2).
    • Distribute elements into buckets based on the current digit.
    • Collect elements back from buckets in order, effectively sorting by that digit.

Advantages

  1. Very efficient for sorting large datasets with keys that are integers or strings with a limited range of characters.
  2. Linear time complexity, independent of the input data distribution.
  3. Stable sorting algorithm.

Disadvantages

  1. Not suitable for general-purpose sorting when the range of values is unknown or very large.
  2. Space complexity can be higher than comparison-based sorting algorithms for smaller datasets.

Pseudo Code

procedure radixSort(A, d, k)
for i = 1 to d
use a stable sort to distribute A to buckets based on digit i
collect elements back from buckets into A

Code in Java

public class RadixSort {
public static void radixSort(int[] arr, int d) {
int radix = 10;
int[] output = new int[arr.length];
int[] count = new int[radix];

for (int i = 0; i < d; i++) {
// Counting sort for each digit
Arrays.fill(count, 0);
for (int j = 0; j < arr.length; j++) {
count[(arr[j] / (int) Math.pow(radix, i)) % radix]++;
}
for (int j = 1; j < radix; j++) {
count[j] += count[j - 1];
}
for (int j = arr.length - 1; j >= 0; j--) {
output[count[(arr[j] / (int) Math.pow(radix, i)) % radix] - 1] = arr[j];
count[(arr[j] / (int) Math.pow(radix, i)) % radix]--;
}
System.arraycopy(output, 0, arr, 0, arr.length);
}
}
}

Code in Python

def radix_sort(arr, d):
radix = 10 # Assuming base 10 for integers
output = [0] * len(arr)
count = [0] * radix

for i in range(d):
# Counting sort for each digit
count = [0] * radix # Reset count array for each digit
for j in range(len(arr)):
digit = (arr[j] // (radix ** i)) % radix # Extract the current digit
count[digit] += 1 # Count occurrences of each digit

# Calculate cumulative counts for stable sorting
for j in range(1, radix):
count[j] += count[j - 1]

# Distribute elements to output array based on sorted positions
for j in range(len(arr) - 1, -1, -1):
digit = (arr[j] // (radix ** i)) % radix
output[count[digit] - 1] = arr[j]
count[digit] -= 1

# Copy the output array back to the original array
arr = output.copy()

return arr
