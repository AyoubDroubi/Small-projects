Everything you need about Algorithms

Calculation, Comparison, Explanation and Documentation

Programmers may face problems understanding some algorithms or not knowing their application

Therefore, we have created a website that helps programmers, and this is through our website that helps them with all matters related to algorithms

The project consists of three parts:

PART 1 :

Calculate Algorithm

You can input an array and choose a sorting algorithm to get the array sorted and determine how much time and space it takes.

The input must be separated by commas.

PART 2 :

Comparison

You can input an array and choose two sorting algorithms to get the array sorted and determine how much time and space each one takes.

You can also generate a random array, and you can choose the array size and the maximum and minimum range of the array values.

The input must be separated by commas.
