Shell-Sort

information

  • Worst Case :  O(n2) - Depends on the gap sequence used, but generally.
  • Average Case :  O(n log(n)2) - Also depends on the gap sequence, but generally.
  • Best Case : O(n log(n)) - When the given array list is already sorted the total count of comparisons of each interval is equal to the size of the given array.
  • Design Technique :  Incremental Technique
  • Space Complexity :  O(1)     -     (in place)

Overview

Shell sort : is mainly a variation of Insertion Sort. In insertion sort, we move elements only one position ahead. When an element has to be moved far ahead, many movements are involved. The idea of ShellSort is to allow the exchange of far items. In Shell sort, we make the array h-sorted for a large value of h. We keep reducing the value of h until it becomes 1. An array is said to be h-sorted if all sublists of every h’th element are sorted.

Definition :  A sorting algorithm that works by repeatedly sorting elements that are a certain distance apart (called the "gap") and gradually reducing the gap until it reaches 1, effectively becoming an insertion sort.

Steps

  1. Choose a gap sequence: Decide on a sequence of gaps to use (e.g., Knuth's sequence).
    • Iterate through the array, comparing elements that are the current gap apart.
    • If elements are in the wrong order, swap them.
    For each gap in the sequence:
  3. Reduce the gap: Move to the next smaller gap in the sequence and repeat step 2.
  4. Continue until the gap is 1: At this point, the array is essentially sorted using insertion sort.

Advantages

  1. More efficient than insertion sort for larger arrays: Due to its pre-sorting at larger gaps.
  2. Adaptive: Takes advantage of existing order in the array.
  3. In-place sorting, no extra memory required.
  4. Relatively simple to implement.

Disadvantages

  1. Worst-case time complexity is not as good as other algorithms like quicksort or merge sort.
  2. Performance depends heavily on the choice of gap sequence.

Pseudo Code

procedure shellSort(A[], n)
for gap = n/2 downto 1
for i = gap to n
j = i
while j >= gap and A[j - gap] > A[j]
swap(A[j], A[j - gap])
j -= gap

Code in Java

public class ShellSort {
public static void shellSort(int[] arr) {
for (int gap = arr.length / 2; gap > 0; gap /= 2) {
for (int i = gap; i < arr.length; i++) {
int temp = arr[i];
int j;
for (j = i; j >= gap && arr[j - gap] > temp; j -= gap) {
arr[j] = arr[j - gap];
}
arr[j] = temp;
}
}
}
}

Code in Python

def shell_sort(arr):
gap = len(arr) // 2


while gap > 0:
for i in range(gap, len(arr)):
temp = arr[i]
j = i
while j >= gap and arr[j - gap] > temp:
arr[j] = arr[j - gap]
j -= gap
arr[j] = temp
gap //= 2

Example

Here's a full example of Shell Sort step by step, using the array [5, 2, 8, 1, 9, 3] and a gap sequence of [3, 1]:



Initial Array: [5, 2, 8, 1, 9, 3]



Gap = 3:



First sub-array (5, 2, 8):

Compare 5 with 8, swap: [8, 2, 5, 1, 9, 3]

Second sub-array (2, 1, 9):

Compare 2 with 9, swap: [8, 9, 5, 1, 2, 3]

Third sub-array (5, 1, 3):

Compare 5 with 1, swap: [8, 9, 1, 5, 2, 3]

Compare 5 with 3, swap: [8, 9, 1, 3, 2, 5]

Gap = 1 (insertion sort):



Iterate through the array:

Compare 8 with 9, no swap.

Compare 9 with 1, swap: [1, 8, 9, 3, 2, 5]

Continue comparisons and swaps as in insertion sort.

Final Sorted Array: [1, 2, 3, 5, 8, 9]



Key points:

It starts with larger gaps to move elements towards their correct positions more quickly.

As the gap decreases, it refines the sorting, eventually becoming insertion sort.

The choice of gap sequence can impact performance.
