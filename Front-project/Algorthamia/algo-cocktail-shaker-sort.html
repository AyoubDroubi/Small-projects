Cocktail Shaker Sort

information

  • Worst Case :  O(n^2)
  • Average Case :  O(n^2)
  • Best Case : O(n) - When the array is already sorted.
  • Design Technique :  Incremental Technique
  • Space Complexity :  O(1)     -     (in place)

Overview

Cocktail Sort : is a variation of Bubble sort. The Bubble sort algorithm always traverses elements from left and moves the largest element to its correct position in the first iteration and second-largest in the second iteration and so on. Cocktail Sort traverses through a given array in both directions alternatively. Cocktail sort does not go through the unnecessary iteration making it efficient for large arrays.

Definition :  A sorting algorithm that iterates through the array in both directions, repeatedly comparing adjacent elements and swapping them if they are in the wrong order. This bidirectional approach can slightly improve performance over standard bubble sort in certain cases.

  2. Iterate through the array from right to left:

  3. Repeat steps 1-2 until no more swaps occur.

Advantages

  1. Simple to understand and implement.
  2. In-place sorting, no extra memory required.
  3. Can be slightly more efficient than bubble sort in certain cases.
  4. Stable sorting algorithm (preserves the order of equal elements).

Disadvantages

  1. Inefficient for large arrays due to its O(n^2) time complexity.
  2. Not as efficient as more advanced sorting algorithms like quicksort or merge sort.

Pseudo Code

procedure cocktailShakerSort(A : list of sortable items)
swapped = true
while swapped do
swapped = false
for i = 0 to length(A) - 2 inclusive do
if A[i] > A[i + 1] then
swap(A[i], A[i + 1])
swapped = true
end for
if not swapped then
break
end if
swapped = false
for i = length(A) - 2 downto 0 inclusive do
if A[i] > A[i + 1] then
swap(A[i], A[i + 1])
swapped = true
end for
end while
end procedure

Code in Java

public class CocktailShakerSort {
public static void cocktailShakerSort(int[] arr) {
boolean swapped;
do {
swapped = false;
for (int i = 0; i < arr.length - 2; i++) {
if (arr[i] > arr[i + 1]) {
swap(arr, i, i + 1);
swapped = true;
}
}
if (!swapped) {
break;
}
swapped = false;
for (int i = arr.length - 2; i >= 0; i--) {
if (arr[i] > arr[i + 1]) {
swap(arr, i, i + 1);
swapped = true;
}
}
} while (swapped);
}

private static void swap(int[] arr, int i, int j) {
int temp = arr[i];
arr[i] = arr[j];
arr[j] = temp;
}
}
